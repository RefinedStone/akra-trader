# Blueprint

Long-horizon product principles. This is not a status document or execution board.

## Product Direction

- Build for one careful operator before adding team workflows.
- Keep research reproducibility ahead of live execution speed.
- Treat sandbox, paper, and guarded live as distinct modes with distinct evidence requirements.
- Require audit, reconciliation, recovery, and stop controls before live readiness.
- Keep LLM work isolated until prompt, trace, replay, evaluation, and fallback controls are real.

## Gate Principles

- Research promotion requires stable strategy identity, dataset boundary, benchmark comparison, and
  reviewable artifacts.
- Runtime promotion requires heartbeat, lag, decision, position, and fill visibility.
- Guarded-live promotion requires venue lifecycle scope, kill-switch drill, reconciliation drill,
  deployment discipline, and credential governance.
- Operational documentation must be shorter than the product workflow it describes.

## Non-Goals

- consumer trading UI
- social or copy-trading features
- multi-user RBAC before the single-operator workflow is reliable
- unattended autonomous live trading
- LLM-driven live execution
